◈ 关于与帮助
  • 本模拟器的 AI 剧情由大语言模型生成,内容可能存在不合理之处
  • API Key 仅保存在你浏览器的 localStorage 中,不会上传到任何服务器
  • 不配置 API Key 也能玩,但会使用站长提供的公共后端(速度较慢)
  • 每个浏览器、每个设备的存档相互独立,换设备需重新配置
  • 如遇异常,可尝试「清除 Key」后重新配置,或「清除剧情历史」后重玩
  • 命薄页和传讯符页的写死对话可以长按删除,删除后可在本页恢复
